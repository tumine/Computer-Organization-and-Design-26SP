## (1)
P1 上程序执行的 CPU 时间 $T_1=\dfrac{1}{4\times 10^9}\times 0.9\times (5\times 10^9) = 1.125s$；

P2 上程序执行的 CPU 时间 $T_2=\dfrac{1}{3\times 10^9}\times 0.75\times (1\times 10^9) = 0.25s$。

可见时钟频率更高的 P1 性能反而不如时钟频率更低的 P2，题目的说法不正确。

## (2)
P1 执行 $1\times 10^9$ 条指令需要的时间是 $T=\dfrac{1}{4\times 10^9}\times 0.9\times (1\times 10^9) = 0.225s$

P2 用同样的时间可以执行的指令数量 $N=\dfrac{T}{\frac{1}{3\times 10^9}\times 0.75}=9\times 10^8$。

## (3)
对于 P1，$MIPS_1=\dfrac{1}{\frac{1}{4\times 10^9}\times 0.9}=4.44\times 10^9$；
对于 P2，$MIPS_2=\dfrac{1}{\frac{1}{3\times 10^9}\times 0.75}=4\times 10^9$。

可见在 $MIPS$ 这个指标上，P1 的表现优于 P2；但前面已知 P1 性能不如 P2，因此题目的说法不正确。

## (4)
仍然假设两种处理器的执行时间都为 $1s$。
对于 P1，$MFLOPS_1=\dfrac{4.44\times 10^9\times 40\%}{1\times 10^6}=1777.78$；

对于 P2，$MFLOPS_2=\dfrac{4\times 10^9\times 40\%}{1\times 10^6}=1600$
