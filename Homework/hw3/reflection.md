### 单周期内容
#### 单周期 CPU 的寻址
- 指令寻址：利用 `PC` 寄存器中的值，到指令内存中查找得到对应内存地址上的值
- 数据寻址：根据指令类型，先完成拼接立即数、到寄存器中取值等操作后，通过 ALU 计算得到最终的访存地址，送入数据内存取该地址上的值

#### 确定 CPU 的时钟周期宽度
- 首先根据选用的 CPU 器件，计算得到各个器件的延迟；
- 对于每种指令，根据其执行的数据通路计算得到指令执行关键路径的延迟；
- 取所有指令延迟中最大值，即为 CPU 需要的最小时钟周期。

#### 如何确保在一个时钟周期内完成一条指令的执行？
- 所有设备在执行一条指令时只能使用一次
  - 如对于 PC+4 的计算，必须采用独立的加法器执行，而不能使用 ALU 执行；计算 PC+4 的加法器不能与计算分支跳转目标地址的加法器合并
  - 指令内存和数据内存必须分开
- CPU 的时钟周期必须满足执行延迟最长的指令需求
  - 对于访存指令，需要考虑到内存访问延迟等大延迟执行过程

#### 能否将两个 adder 合二为一，或将指令内存与数据内存合并？
如上所述，由于单周期 CPU 需要在一个时钟周期内执行完成一条指令，为保证每个模块输出的可靠性，执行路径上的每个器件只能使用一次。因此，不能将计算 PC+4 的加法器与计算分支跳转目标地址的加法器合并（否则，整合后的加法器需要先计算出 PC+4，再以此作为自身输入计算出分支跳转地址，这个过程与当前实际执行的指令是否是条件分支跳转指令无关）；也不能将指令内存与数据内存合并。

### 多周期内容
#### 每一类指令的指令周期各含多少个时钟周期？每个周期中用到什么功能部件？
- R 型指令：4 个时钟周期
  - 第 1 个周期（取指）：PC（输出指令地址、写入自增地址）、内存（读取指令机器码）、ALU（计算 PC+4）
  - 第 2 个周期（译码）：寄存器堆（读取寄存器 `rs1` 和 `rs2`）
  - 第 3 个周期（执行）：ALU（进行运算）
  - 第 4 个周期（写回）：寄存器堆（将 ALU 计算结果写回 `rd`）
- I 型算术逻辑指令：4 个时钟周期
  - 第 1 个周期（取指）：PC（输出指令地址、写入自增地址）、内存（读取指令机器码）、ALU（计算 PC+4）
  - 第 2 个周期（译码）：寄存器堆（读取 `rs1`）、立即数生成器
  - 第 3 个周期（执行）：ALU（进行运算）
  - 第 4 个周期（写回）：寄存器堆（将 ALU 计算结果写回 `rd`）
- I 型访存读取指令（Load）：5 个时钟周期
  - 第 1 个周期（取指）：PC（输出指令地址、写入自增地址）、内存（读取指令机器码）、ALU（计算 PC+4）
  - 第 2 个周期（译码）：寄存器堆（读取 `rs1`）、立即数生成器
  - 第 3 个周期（执行）：ALU（计算内存地址）
  - 第 4 个周期（访存）：内存（根据 ALU 结果读取数据）
  - 第 5 个周期（写回）：寄存器堆（将读出的内存数据写回 `rd`）
- S 型指令：4 个时钟周期
  - 第 1 个周期（取指）：PC（输出指令地址、写入自增地址）、内存（读取指令机器码）、ALU（计算 PC+4）
  - 第 2 个周期（译码）：寄存器堆（读取 `rs1` 和 `rs2`）、立即数生成器
  - 第 3 个周期（执行）：ALU（计算内存地址）
  - 第 4 个周期（访存）：内存（将 `rs2` 数据写入所计算出的内存地址）
- SB 型指令：3 个时钟周期
  - 第 1 个周期（取指）：PC（输出指令地址、写入自增地址）、内存（读取指令机器码）、ALU（计算 PC+4）
  - 第 2 个周期（译码）：寄存器堆（读取 `rs1` 和 `rs2`）、立即数生成器、ALU（计算分支目标地址 PC + Imm）
  - 第 3 个周期（执行）：ALU（比较 `rs1` 和 `rs2`）、PC（若满足分支条件，将分支目标地址写入 PC）
- U 型指令：4 个时钟周期
  - 第 1 个周期（取指）：PC（输出指令地址、写入自增地址）、内存（读取指令机器码）、ALU（计算 PC+4）
  - 第 2 个周期（译码）：立即数生成器
  - 第 3 个周期（执行）：ALU（计算 Imm << 12 或 PC + (Imm << 12)）
  - 第 4 个周期（写回）：寄存器堆（运算结果写回 `rd`）
- UJ 型指令：3 个时钟周期
  - 第 1 个周期（取指）：PC（输出指令地址、写入自增地址）、内存（读取指令机器码）、ALU（计算 PC+4）
  - 第 2 个周期（译码）：立即数生成器、ALU（计算目标地址 PC + Imm）
  - 第 3 个周期（执行）：PC（写入分支目标地址）、寄存器堆（将 PC+4 写入 `rd`）
